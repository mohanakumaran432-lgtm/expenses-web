# expenses-web

A private, offline personal expense tracker for the iPhone Home Screen. Plain HTML, CSS and JavaScript, no dependencies, no network calls, no accounts.

**Status: work in progress. Not published and not ready for real financial data.** It has only been tested in desktop Chromium, never on a real iPhone. Still to do: offline support (service worker), Home Screen icons and manifest, PDF reports, and a real-iPhone test pass.

The site lives in `docs/`. Tests: `npm test` (unit, Node 22) and `tests/e2e/` (browser, Playwright + Chromium).
